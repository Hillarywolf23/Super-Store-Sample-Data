# Sales & Profit Insights Dashboard

Welcome to my portfolio repository! This project showcases an interactive Tableau dashboard that provides key insights into sales and profit performance across various dimensions. The dashboard is built using sample data and is designed to highlight regional, temporal, and product-level trends.

## Overview

This dashboard includes the following visualizations:

- **Profit by State:**  
  A map that displays the profit percentage for each state, allowing for quick identification of high and low-performing regions.

- **Profit Over Time:**  
  A line chart that tracks profit trends across different time periods (year, month, and quarter), highlighting seasonal fluctuations and overall performance trends.

- **Least Profitable Sub-Category:**  
  A bar chart that identifies the product sub-category with the lowest profit, providing insight into potential areas for improvement.

- **Regional Sales Distribution:**  
  A pie chart that illustrates the percentage contribution of sales from different regions (West, East, Central, and South), offering a complementary perspective to the profit-focused analyses.

## Data

The sample dataset includes fields such as:
- Category, City, Country/Region, Customer ID, Customer Name, Order Date, Order ID, Order Profitable?, Postal Code, Product ID, Product Name, Region, Row ID, Segment, Ship Date, Ship Mode, Ship Status, State, Sub-Category, Days to Ship Actual, Days to Ship Scheduled, Discount, Profit, Quantity, Sales, and Sales Forecast.
